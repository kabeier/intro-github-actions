Homework Part I: Hello Workflows

Start a new repository with one workflow that: runs on every push, on all branches · sets up Ubuntu · uses a shell command to echo Hello Workflows. Then 50 steps of your current FreeCodeCamp certification.

1 · The repo and the workflow

  1. New public repo on github.com (no README), then mkdir it, git init, mkdir -p .github/workflows, code . (Code Lab 1, section 1).
  2. .github/workflows/hello-workflows.yml. Try writing it yourself from Lecture 1 first; then compare:
    Show a working version
    name: Hello Workflows

on:
  push:

jobs:
  hello:
    runs-on: ubuntu-latest
    steps:
      - name: Say hello
        run: echo "Hello Workflows"
  3. Commit, push to main, then push a second branch: it should run on both. 
    git add .
git commit -m "Hello Workflows"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main

    Done = a green ✓ in the Actions tab, and "Hello Workflows" printed in the step's output. If this breaks: no run at all = check the folder is exactly .github/workflows/. "Invalid workflow file" = indentation (spaces, not tabs).

Homework Part II: Adding Workflows

Go back to every assignment you've done that has a test suite and add a workflow that runs it. That's the pytest and Jest assignments: Roman Numerals and Linear Search (pytest), Fibonacci and Linear Search (Jest), Test my Calculator (pytest). Then 50 steps of your current FreeCodeCamp certification.

2 · Jest repos

  1. In each Jest repo (they already list Jest in package.json): .github/workflows/run-jest.yml 
    name: Run Jest Tests

on:
  push:
  pull_request:
    branches:
      - main
  workflow_dispatch:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Node.js
        uses: actions/setup-node@v4
        with:
          node-version: 18

      - name: Install dependencies
        run: npm install

      - name: Run tests
        run: npm test

3 · pytest repos

  1. In each pytest repo: .github/workflows/run-pytest.yml 
    name: Run pytest

on:
  push:
  pull_request:
    branches:
      - main
  workflow_dispatch:

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repository
        uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v5
        with:
          python-version: "3.12"

      - name: Install pytest
        run: pip install pytest

      - name: Run tests
        run: pytest
    setup-python gives you Python, not pytest: keep the pip install pytest step.

4 · Push and check

  1. Commit and push each repo: 
    git add .github
git commit -m "Run the tests in GitHub Actions"
git push
    Or ask Claude (in the repo folder): 
    Run git status and show me the list of files. Then suggest a commit message for adding a GitHub Actions workflow and wait for my approval. After I approve, commit and push to my fork.
  2. Done = each repo's Actions tab shows a run. Green ✓ if your solution passes; red ✗ if a test fails (that's the workflow doing its job: read the log).

    If this breaks: pytest: command not found = missing pip install pytest. jest: not found = run npm install (or add Jest). ENOENT … package.json = missing actions/checkout. Both templates ran green in the demo repo (branches template-jest and template-pytest).
