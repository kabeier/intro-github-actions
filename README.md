# GitHub Actions

Lecture site for Code Platoon Phase I, **Fundamentals: GitHub Actions**: workflows that run your tests on every push and pull request. Students push their own repos and read the Actions tab.

**Live site:** https://kabeier.github.io/intro-github-actions/
