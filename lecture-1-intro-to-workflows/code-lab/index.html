Code Lab 1: your first workflow

Follow along with Lecture 1. You'll make a repo, add a workflow, push it, and watch GitHub run it in the Actions tab. Then you'll limit it to one branch and watch it not run. Everything here was run for real in kabeier/gh-actions-demo.

In classSections 1–4 follow the slides. Something broke?Jump to the table at the bottom.

1 · A new repo

  1. On github.com: + → New repository → name it hello-actions, Public, don't add a README → Create repository.
  2. In your terminal: 
    mkdir hello-actions
cd hello-actions
git init
mkdir -p .github/workflows
code .
    Windows PowerShell: mkdir .github/workflows also works.

2 · hello-world.yml

In VS Code, create .github/workflows/hello-world.yml (a dot before github, workflows with an s). Type it; indent with spaces:

name: Hello World Workflow

on:
  push:

jobs:
  say-hello:
    runs-on: ubuntu-latest
    steps:
      - name: Print a message
        run: echo "Hello from GitHub Actions!"
LineMeans
nameAny name. Name it after what it does.
on: pushRun on every push. No branches listed = any branch.
jobs → say-helloOne job (one task for the robot).
runs-onThe machine: a fresh Ubuntu every time.
stepsLabeled steps. run = a terminal command.

3 · Push it and open the Actions tab

git add .
git commit -m "Add hello world workflow"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/hello-actions.git
git push -u origin main

On github.com, open your repo → Actions → Hello World Workflow → the run → say-hello → expand Print a message. A yellow dot means it's running; a green ✓ means done. You should see:

✓ Set up job
✓ Print a message
    Run echo "Hello from GitHub Actions!"
    Hello from GitHub Actions!
✓ Complete job

4 · A branch filter: watch it not run

  1. Change the trigger in hello-world.yml to: 
    on:
  push:
    branches:
      - main
    git commit -am "Only run on main"
git push
    Actions: a new run, for main.
  2. Now push a different branch: 
    git checkout -b try-filter
echo "test" >> notes.txt
git add .
git commit -m "Change on a branch"
git push -u origin try-filter
    Actions: no new run for try-filter. That's correct: the filter said main only.
  3. Go back: git checkout main.

The other triggers from the lecture: pull_request: branches: - main runs for pull requests into main; schedule: - cron: "0 0 * * *" runs daily at midnight UTC.

Check: you're done when…

  1. Your repo's Actions tab shows a green ✓ "Hello World Workflow" run with "Hello from GitHub Actions!" in its output
  2. You pushed try-filter and saw that it did not run
